# Оптимизация батареи — Nubia NX721J (cerro)

Прошивка содержит ряд изменений для улучшения автономности. Часть работает сама, часть нужно настроить вручную после первой загрузки.

---

## Что уже сделано в прошивке

**Дисплей**
Экран теперь умнее переключается между 120 и 60 Гц. При просмотре видео автоматически применяется 60 Гц. Если экран ничего не обновляет (лаунчер, статичная страница) — через полсекунды тоже уходит на 60 Гц.

**Процессор**
Включён энергоэффективный режим управления частотой процессора (schedutil). Раньше частота выбиралась «на глаз», теперь — по реальной нагрузке. Пиковые частоты урезаны: в обычных задачах разницы нет, в тяжёлых играх плавность может чуть просесть.

**Тепловой пакет**
Термальные лимиты снижены — телефон реже греется под нагрузкой, но при длительных нагрузках (игры 30+ минут) производительность может ограничиваться чуть раньше, чем в стоке.

**Мобильный интернет**
Когда телефон подключён к Wi-Fi и экран выключен, мобильный модем переходит в режим пониженного потребления. Звонки и SMS работают в штатном режиме.

**Прочее**
Исправлен заряд батареи в настройках (был занижен), убрано избыточное логирование системных служб.

## Что нужно сделать вручную (один раз после прошивки)

### 1. Тип сети — важно
Если 5G не нужен или покрытие нестабильное:
`Настройки → Сеть и интернет → SIM-карты → каждая SIM → Тип сети → LTE`

Модем SM8650 постоянно ищет 5G даже на LTE — это заметно садит батарею.

### 2. Telegram
`Настройки → Приложения → Telegram → Батарея → Ограничить`

По логам Telegram потреблял ~40 мАч через мобильный интернет пока экран был выключен. Это ~15% суточного заряда уходит только на фоновые соединения Telegram.

### 3. MicroG (если используешь ReVanced)
`MicroG → Google Cloud Messaging → Heartbeat interval → 28 минут`

По умолчанию 15 минут — каждые 15 минут будит процессор для проверки push-уведомлений.

### 4. Nearby Share / Chromecast
`Настройки → Google → Устройства и общий доступ → Nearby Share → выключить`

Пока включено — телефон держит Wi-Fi в режиме «слушать всех» для обнаружения устройств.

### 5. Приложения банков
Тинькофф, Сбер, ВТБ и аналоги — ограничить фоновую работу:
`Настройки → Приложения → [приложение] → Батарея → Ограничить`

### 6. После звонков
Известный баг Google Dialer: датчик приближения иногда не отключается после завершения звонка. Если батарея начала садиться быстрее после звонка — принудительно остановите приложение «Телефон» через Настройки → Приложения.

## Ожидаемый результат

| Режим | До | После (ожидаемо) |
|---|---|---|
| Экран выключен | ~73 мАч/ч | ~35–45 мАч/ч |
| Экран включён | без изменений | без изменений |
| Заряда на сутки | ~8–10 часов экрана | ~12–15 часов экрана |

Точные цифры зависят от оператора, сигнала и использования.

---

## Если нужен максимум производительности

Если хочется выжать максимум скорости в играх:

1. **Включить 5G** — `Настройки → Сеть и интернет → SIM → Тип сети → 5G`
2. **Снять ограничения частот** — `Настройки Nubia → Производительность → Ограничение частот → выключить`

После этого телефон будет работать на полных частотах, но батарея будет садиться заметно быстрее.
